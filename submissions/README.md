# 지표 설계 결과 제출

개인 브랜치 `students/참가자번호`의 `submissions/metric.json`으로 제출합니다.

`python lab.py submit`이 지표 정의, 계산 결과와 데이터 식별값을 저장하고 해당 파일만 커밋하여 개인 브랜치로 푸시합니다. 기본 자료는 `log_pairs/`의 재구성한 교육용 로그입니다. 자료 검증에 실패하거나 계산할 수 없는 지표는 제출하지 않습니다.

제출 후 GitHub Actions의 **Collect student metrics → practice2-sharing**에서 강사가 다시 계산한 공유 자료를 확인합니다. 같은 명령으로 재제출할 수 있으며, 새 clone에서 같은 참가자 번호로 등록하면 마지막 제출한 지표가 복원됩니다. 자세한 순서는 [수강생 시나리오](../docs/student-workflow.md)를 참고하세요.

이 실습은 지표의 순위를 매기지 않습니다. 평가 목적과 계산 방법, 담당 업무에서의 활용 이유를 함께 공유합니다.
