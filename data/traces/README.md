# 분석용 실행 기록

실행별 `실행ID.jsonl`에 명령, 이벤트 종류, 종료 코드와 관측 시각을 기록합니다. 현재 실제 기록은 없습니다.

실습 1 변환 도구는 원본 이벤트에서 이 항목들을 추출합니다. 도구 출력 본문 대신 바이트 길이와 해시를 남기므로, 원본 로그 전체와 동일한 파일은 아닙니다. 원본 로그는 강사진이 별도로 보관합니다.

수강생은 지표의 차이를 해석할 때 실제로 어떤 문서를 조회하거나 어떤 테스트를 반복했는지 이 기록과 함께 확인합니다. 관측 시각이 없는 이벤트에 시간을 추정해서 넣지 않습니다.

공개 전에 명령 문자열에 불필요한 개인 경로나 인증 정보가 포함되어 있지 않은지 확인합니다.
