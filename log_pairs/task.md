[ISSUE-142] 제휴 쿠폰을 출차 정산에 반영

배경
한결몰·한결타워 제휴 매장 쿠폰을 9월 15일부터 출차 정산에 반영한다. 쿠폰 데이터(data/coupons.json)와 조회 명령(parkfee coupon show)은 1.6.0에 이미 있다.

요구사항
1. `parkfee calc`에 `--coupon <쿠폰코드>` 옵션을 추가한다. 쿠폰은 `--data-dir`의 coupons.json에서 찾는다. 없는 코드는 `coupon show`와 같은 오류(E2001)로 처리한다.
2. 쿠폰 적용 규칙은 회사 운영 규정을 따른다.
3. `--format json` 출력에 `coupon` 필드를 추가한다.
   - 쿠폰을 지정하지 않으면 `null`
   - 지정하면 `{"code": "<쿠폰코드>", "status": "<처리 결과>"}`
   - status 값: `applied`(정산에 사용함), `unused`(사용하지 않고 반환함), `expired`(유효기간이 지나 적용하지 않음)
4. 텍스트 영수증에도 쿠폰 코드와 처리 결과를 표시한다.
5. 기존 테스트는 모두 통과해야 하고, 쿠폰 관련 테스트를 추가한다.
