# 요구사항 명세

| 항목 | 내용 |
|---|---|
| 문서 번호 | PRD-REQ-002 |
| 버전 | 2.6 (2026-08-28) |
| 작성 | 이서연 (서비스기획팀) |
| 승인 | 최현우 (서비스기획팀장) |

요구사항의 계산 규칙은 각 운영 규정을 따릅니다. 이 문서는 "무엇을 해야 하는가"만 적고, 계산 방법은 규정 조항으로 연결합니다.

## 1. 기능 요구사항

| ID | 요구사항 | 근거 | 상태 |
|---|---|---|---|
| FR-01 | 입차·출차 시각으로 주차 시간(분)을 산정한다 | 요금 규정 제4조 | 완료 (1.0.0) |
| FR-02 | 주차장별 요금표로 할인 전 요금을 계산한다 | 요금 규정 제3·6조 | 완료 (1.0.0) |
| FR-03 | 일 최대 요금을 입차 시각부터 24시간 단위로 적용한다 | 요금 규정 제7조 | 완료 (1.0.0) |
| FR-04 | 회차 시간 이내 출차는 무료로 처리한다 | 요금 규정 제5조 | 완료 (1.0.0) |
| FR-05 | 감면 대상 차량에 감면을 적용한다 | 할인·감면 규정 제2장 | 완료 (1.0.0) |
| FR-06 | 멤버십 회원에게 멤버십 할인을 적용한다 | 할인·감면 규정 제3장 | 완료 (1.1.0) |
| FR-07 | 결제 금액의 100원 미만을 절사하고 부가세를 분리 표시한다 | 요금 규정 제10·11조 | 완료 (1.4.1) |
| FR-08 | 환승주차장은 24시간 단위 정액 요금을 부과한다 | 요금 규정 제8조 | 완료 (1.0.0) |
| FR-09 | 유효한 정기권 차량은 무료로 처리한다 | 정기권 규정 제4조 | 완료 (1.2.0) |
| FR-10 | 하루치 입출차 기록으로 주차장별 정산 리포트를 만든다 | 일일 정산 마감 절차 | 완료 (1.1.0) |
| FR-11 | 운영자가 쿠폰 코드로 쿠폰 내용을 조회한다 | UC-06 | 완료 (1.6.0) |
| FR-12 | 출차 정산에 제휴 쿠폰을 반영한다 | 할인·감면 규정 제5장 | 개발 예정 (2026-09-15 시행) |

## 2. 비기능 요구사항

| ID | 요구사항 | 기준 |
|---|---|---|
| NFR-01 | 정확성 | 규정 대비 금액 오차 0원. 금액은 정수 원 단위로만 계산 |
| NFR-02 | 성능 | 출차 1건 정산 10ms 이내 (정산기 응답 목표 1초 중 엔진 몫) |
| NFR-03 | 이식성 | 표준 라이브러리만 사용. 정산기 펌웨어 번들(Python 3.10)에서 동작 |
| NFR-04 | 변경 용이성 | 요금표·감면율 변경은 코드 수정 없이 데이터 파일 교체로 반영 |
| NFR-05 | 테스트 | 라인 커버리지 90% 이상, 규정 조항별 테스트 존재 |
| NFR-06 | 개인정보 | 로그에 차량번호 전체를 남기지 않음 |
| NFR-07 | 추적성 | 정산 결과에 적용된 할인 내역을 모두 남김 |
