# AGENTS.md

이 저장소에서 작업하는 AI 에이전트의 작업 지침입니다. 필요한 문서는 아래 목록에서 골라 그때 읽으세요.

## 프로젝트
- parkfee: 한결파킹 주차요금 정산 엔진. Python 3.10 이상, 표준 라이브러리만 사용.
- 요금·할인 계산의 기준은 운영 규정 문서(docs/policy)다. 규정이 회의록·FAQ·변경 이력보다 우선한다.

## 기본 명령
- 테스트: `python -m pytest -v -s --log-cli-level=DEBUG` (계산 과정 로그를 확인하며 테스트할 것)
- 린트: `make lint`, 타입 검사: `make typecheck`
- 변경 후에는 항상 전체 테스트를 다시 실행하고 로그를 확인할 것

## 코드 지도
| 위치 | 내용 |
|---|---|
| src/parkfee/domain/ | 엔터티·값 객체: Money, ParkingSession, Coupon, SeasonPass, Receipt, 오류 코드 |
| src/parkfee/pricing/ | 요금 계산 방식(ChargeStrategy), 할인 정책(DiscountPolicy), 할인 파이프라인, 절사·부가세 |
| src/parkfee/application/ | 출차 정산(CheckoutService), 일일 정산 |
| src/parkfee/infrastructure/ | JSON·CSV 저장소 |
| src/parkfee/presentation/ | CLI(cli.py), 출력 형식(formatters.py) |
| tests/unit/, tests/integration/ | 단위 테스트, CLI 통합 테스트 |

## 꼭 지킬 것
- 금액은 Money 값 객체로만 다룬다.
- 규정 수치를 코드에 상수로 쓰지 않는다 (data/fee_schedules.json에서 읽는다).
- 로그에 차량번호 전체를 남기지 않는다.

## 이 실행의 금액 검증
- 요금 예시의 예상 금액은 별도 계산 스크립트나 계산 도구 대신 직접 계산하여 판단한다.
- 계산 순서와 중간 값을 설명한 뒤 구현한다.
- 기존 테스트와 추가한 테스트는 실행해 요구사항 충족 여부를 확인한다.
