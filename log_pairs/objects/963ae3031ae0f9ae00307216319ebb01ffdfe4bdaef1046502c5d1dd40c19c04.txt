# 장애 보고서: 한결몰 일일 정산 불일치

| 항목 | 내용 |
|---|---|
| 등급 | S2 |
| 발생 | 2026-05-12 ~ 2026-05-19 |
| 탐지 | 2026-05-19 09:20 정산팀 대사 (매출 대사 차이 알림) |
| 복구 | 2026-05-20 parkfee 1.4.1 배포 |
| 작성 | 김민준 (정산플랫폼팀) |

## 요약
1.4.0 배포 후 감면 차량의 결제 금액에 100원 미만 절사가 적용되지 않아, 규정보다 최대 90원 많게 계산되었다. 8일간 1,124건, 과다 청구 합계 51,300원은 전액 환불했다.

## 타임라인
- 05-12 02:00 parkfee 1.4.0 정산기 반영 (쿠폰 시범 코드 제거 리팩터링 포함)
- 05-19 09:20 정산팀이 HJ-02 매출 대사 차이 1만 원 초과 확인
- 05-19 11:00 원인 확인: 감면 적용 **전에** 100원 미만 절사
- 05-20 02:00 1.4.1 배포

## 원인
쿠폰 시범 코드를 제거하면서 할인 함수 순서를 옮겼고, 절사가 감면보다 앞에 놓였다. 그 결과 감면 후 금액에는 절사가 다시 적용되지 않았다. 기존 테스트는 감면 결과가 100원 단위로 떨어지는 금액만 써서 순서가 바뀌어도 통과했다.

예: 한결몰 50분 주차, 국가유공자 50%
- 규정대로: 2,500원 → 감면 1,250원 → 1,250원 → 절사 → **1,200원**
- 오류: 2,500원 → 절사(변화 없음) → 감면 1,250원 → **1,250원** (50원 과다)

## 재발 방지
| 조치 | 담당 | 상태 |
|---|---|---|
| 요금 규정 제10조에 "모든 할인 적용 후 1회 절사" 명시 (v3.0) | 이서연 | 완료 |
| 순서가 틀리면 실패하는 숫자로 테스트 작성 규칙 추가 (테스트 전략 v2.0) | 정하늘 | 완료 |
| 리뷰 체크리스트에 "절사가 마지막 한 번뿐인가" 추가 | 임재현 | 완료 |
| 매출 대사 알림 기준을 3만 원에서 1만 원으로 낮춤 | 정소영 | 완료 |

## 교훈
- 계산 순서는 규정 문서에 명시하고, 테스트는 순서를 바꾸면 결과가 달라지는 숫자로 쓴다.
- 리팩터링 PR과 기능 제거 PR을 섞지 않는다.
