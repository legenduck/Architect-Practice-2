# 보안 정책

## 취약점 신고

parkfee 또는 연동 시스템에서 보안 취약점을 발견하면 공개 채널에 올리지 말고 정보보호팀 메일(security@hangyeol-parking.example)로 알려 주세요.
신고 시 재현 방법, 영향 범위, 발견 일시를 함께 적어 주시면 1영업일 안에 접수 회신을 드립니다.

## 처리 기준

| 등급 | 예시 | 조치 목표 |
|---|---|---|
| 긴급 | 결제 금액 조작, 개인정보 대량 노출 | 24시간 이내 임시 조치 |
| 높음 | 요금 계산 우회, 인증 없는 데이터 접근 | 3영업일 이내 수정 배포 |
| 보통 | 로그의 개인정보 마스킹 누락 | 다음 정기 배포 |

## 개발 시 지켜야 할 것

- 로그·화면 출력에 차량번호 전체를 남기지 않습니다 (`mask_plate` 사용). 단, 고객에게 발급하는 영수증은 예외입니다.
- 결제 카드 정보는 parkfee가 다루지 않습니다. 결제는 PG사 연동 모듈에서 처리합니다.
- 데이터 파일은 저장소의 샘플만 커밋합니다.
