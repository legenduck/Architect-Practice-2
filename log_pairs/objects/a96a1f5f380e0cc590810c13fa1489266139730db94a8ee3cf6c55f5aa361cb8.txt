# ADR-004 요금표·감면율을 데이터 파일로 분리

- 상태: 승인
- 날짜: 2025-07-10
- 결정자: 김민준, 정소영(정산팀)

## 배경
요금 개정 때마다 코드 상수를 고치고 정산기 펌웨어까지 다시 배포해야 했다. 2025년 상반기에만 요금표가 세 번 바뀌었다.

## 결정
- 요금표, 회차 시간, 멤버십 할인율, 감면율, 절사 단위를 `fee_schedules.json`으로 분리한다.
- 쿠폰과 정기권도 각 시스템이 내보내는 JSON 파일로 읽는다.
- 파일 형식 검증은 로더가 하며, 문제가 있으면 `DataFileError(E3001)`로 실패한다. 잘못된 요금표로 정산하는 것보다 정산을 멈추는 것이 낫다.

## 결과
- 요금 개정은 승인된 데이터 파일 교체로 배포한다(배포 절차 참고).
- 계산 규칙 자체(순서, 반올림 방식)는 여전히 코드이므로, 규칙이 바뀌면 코드 변경이 필요하다.
