# 일일 정산 마감 절차

| 항목 | 내용 |
|---|---|
| 문서 번호 | OPS-SET-003 |
| 버전 | 1.2 (2026-05-25) |
| 담당 | 정산팀 (정소영) |

## 1. 기준
- 영업일은 출차 시각이 속한 날짜(00:00~23:59)입니다. 전날 입차해 오늘 출차한 차량은 오늘 매출입니다.
- 매일 01:00 배치 서버가 전 영업일 입출차 기록 CSV를 만듭니다.

## 2. 절차
1. 01:30 배치가 다음 명령으로 리포트를 만듭니다.
   ```bash
   parkfee --data-dir /opt/parkfee/data batch /data/exports/sessions_<영업일>.csv --format json
   ```
2. 09:00 정산팀이 리포트 매출과 PG 승인 합계를 대사합니다.
3. 차이가 1만 원을 넘으면 [장애 대응 런북](incident-runbook.md) 2.3절에 따라 원인을 찾습니다.
4. 대사가 끝나면 정산 시스템에 마감을 등록합니다.

## 3. 주의
- 리포트의 `revenue`는 절사 후 금액의 합이라 `charge - discount`와 다를 수 있습니다.
- 수동 정산(입차 기록 없음, 정산기 장애) 건은 CSV에 포함되지 않으므로 운영팀 수동 정산 대장과 합산합니다.
- 제휴 쿠폰 청구는 월말에 제휴운영팀이 별도로 합니다 ([제휴 쿠폰 발급·정산 절차](../policy/partner-coupon-issuance.md)).
