# 제휴 쿠폰 발급·정산 절차

| 항목 | 내용 |
|---|---|
| 문서 번호 | OPS-CPN-004 |
| 버전 | 1.1 (2026-08-20) |
| 소유 부서 | 제휴운영팀 (담당 강태오) |

이 문서는 쿠폰을 **발급하고 제휴 매장에 청구하는 절차**를 다룹니다. 출차 정산에서 쿠폰을 어떻게 적용하는지는 「할인·감면 규정」 제5장을 따릅니다.

## 1. 발급 주체와 시스템

- 쿠폰은 제휴운영팀이 관리하는 제휴운영 시스템에서 발급합니다.
- 제휴 매장 POS가 발급 요청을 보내면 쿠폰 코드가 영수증 하단에 바코드로 인쇄됩니다.

## 2. 쿠폰 코드 체계

| 형식 | 의미 | 예 |
|---|---|---|
| `HJM-YYMM-NNNN` | 한결몰(HJ-02) 발급, 발급 연월, 일련번호 | HJM-2609-0001 |
| `HJT-YYMM-NNNN` | 한결타워(HJ-01) 발급, 발급 연월, 일련번호 | HJT-2609-0002 |

한결역 환승주차장(HJ-03)은 제휴 쿠폰을 발급하지 않습니다.

## 3. 발급 기준 (2026년 9월 기준)

| 매장 | 쿠폰 | 발급 조건 |
|---|---|---|
| 한결시네마 | 시간 쿠폰 60분 | 영화 관람 1회 |
| 한결마트 | 시간 쿠폰 120분 | 5만 원 이상 구매 |
| 카페 온새미로 | 금액 쿠폰 1,000원 | 음료 2잔 이상 |
| 책마루 서점 | 금액 쿠폰 3,000원 | 9월 행사 기간 3만 원 이상 구매 |
| 한결타워 라운지 카페 | 시간 쿠폰 30분 | 방문객 음료 구매 |
| 한결타워 컨퍼런스센터 | 금액 쿠폰 2,000원 | 행사 당일 참가자 |

## 4. 유효기간

- 기본 유효기간은 발급일 00:00부터 발급월 말일 23:59:59까지입니다.
- 행사 쿠폰은 행사 기간에 맞춰 따로 정합니다.

## 5. 데이터 연동

- 제휴운영 시스템은 매일 05:00에 쿠폰 목록을 `coupons.json` 형식으로 내보내고, 정산기·앱 백엔드의 데이터 디렉터리에 배포합니다.
- 형식은 「데이터 모델」 문서를 따릅니다.

## 6. 제휴 매장 청구

- 매월 말일 기준으로 **사용 처리된 쿠폰만** 제휴 매장에 청구합니다. 반환되거나 만료된 쿠폰은 청구하지 않습니다.
- 시간 쿠폰은 사용 1시간당 1,500원(30분 쿠폰은 750원), 금액 쿠폰은 액면 금액을 청구합니다.
- 청구서는 정산팀이 다음 달 5영업일까지 발송합니다.

## 7. 시범 운영 이력

- 2026년 3~4월 한결몰에서 시범 운영했습니다. 시범 기간에는 쿠폰을 감면·멤버십 할인과 중복 사용할 수 있었고, 유효기간은 입차 시각 기준으로 확인했습니다.
- 시범 운영은 2026-04-10에 종료했습니다. 2026-09-15부터 적용하는 정식 규칙은 「할인·감면 규정」 v2.3 제5장입니다.
