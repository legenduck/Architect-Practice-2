# 용어집

| 용어 | 정의 |
|---|---|
| 주차 시간 | 출차 시각 − 입차 시각. 1분 미만은 1분으로 올린다. |
| 회차 | 입차 후 회차 시간 이내에 출차하는 것. 요금을 받지 않는다. 주차장마다 회차 시간이 다르다. |
| 기본 요금 | 최초 기본 시간(30분)까지 부과하는 요금. |
| 단위 요금 | 기본 시간 이후 단위 시간(10분)마다 부과하는 요금. 단위 시간 미만도 1단위로 센다. |
| 일 최대 요금 | 입차 시각부터 24시간 구간마다 부과할 수 있는 요금의 상한. |
| 정액제 | 시간과 관계없이 시작된 24시간마다 같은 금액을 부과하는 방식 (환승주차장). |
| 감면 | 장애인·국가유공자·경형·저공해 자동차에 적용하는 비율 할인. 여러 개에 해당해도 하나만 적용한다. |
| 멤버십 할인 | 한결 멤버십 회원에게 감면 후 금액 기준으로 적용하는 할인. |
| 정기권 | 등록 차량 1대가 한 주차장을 한 달 동안 무료로 이용하는 권리. |
| 제휴 쿠폰 | 제휴 매장이 고객에게 발급하는 주차 쿠폰. 시간 쿠폰과 금액 쿠폰이 있다. |
| 시간 쿠폰 | 정해진 분만큼 무료 주차를 제공하는 쿠폰. |
| 금액 쿠폰 | 정해진 금액을 요금에서 빼 주는 쿠폰. |
| 쿠폰 반환 | 쿠폰을 사용 처리하지 않고 고객에게 돌려주는 것. 반환된 쿠폰은 유효기간 안에 다시 쓸 수 있다. |
| 절사 | 결제 금액의 100원 미만을 버리는 것. |
| 공급가액 / 부가세 | 결제 금액(부가세 포함)을 1.1로 나눈 값과 나머지. |
| 영업일 | 출차 시각이 속한 날짜(00:00~23:59). 일일 정산의 기준. |
| LPR | License Plate Recognition. 번호인식 카메라. |
| 사전 정산 | 출차 전에 앱이나 로비 정산기로 미리 결제하는 것. |
