## 기본 명령
- 테스트: `python -m pytest -v -s --log-cli-level=DEBUG` (계산 과정 로그를 확인하며 테스트할 것)
- 린트: `make lint`, 타입 검사: `make typecheck`
- 변경 후에는 항상 전체 테스트를 다시 실행하고 로그를 확인할 것

# 코딩 컨벤션

| 항목 | 내용 |
|---|---|
| 문서 번호 | DEV-CONV-001 |
| 버전 | 1.5 (2026-06-03) |
| 작성 | 임재현 (정산플랫폼팀) |

## 1. 기본
- PEP 8을 따르며 `ruff`가 기준입니다. 한 줄은 100자까지입니다.
- 모든 함수와 메서드에 타입 힌트를 붙입니다. `mypy --strict`를 통과해야 합니다.
- 모든 모듈 첫 줄에 `from __future__ import annotations`를 둡니다.
- Python 3.10 문법까지만 씁니다. (`match` 문은 팀 합의로 사용하지 않습니다.)

## 2. 이름
- 모듈·함수·변수: `snake_case`, 클래스: `PascalCase`, 상수: `UPPER_SNAKE_CASE`.
- 도메인 용어는 [용어집](../product/glossary.md)의 영문 표기를 따릅니다: 회차 `grace`, 감면 `reduction`, 일 최대 요금 `daily_max`, 정기권 `season_pass`, 절사 `rounding`.
- 불리언은 `is_`, `has_` 접두사나 `*_applied` 접미사를 씁니다.

## 3. 도메인 규칙
- 금액은 `Money`로만 다룹니다. `int`로 꺼내는 것은 출력 직전(`Money.won`)뿐입니다 (ADR-002).
- 시각은 타임존 없는 `datetime`(KST)으로 다룹니다. `datetime.now()`를 계산 로직에서 직접 부르지 않습니다.
- 규정 수치(요금, 비율, 회차 시간)를 코드에 상수로 쓰지 않습니다. `fee_schedules.json`에서 읽습니다 (ADR-004).
- 계층 의존 규칙은 [아키텍처 개요](../architecture/overview.md)를 따릅니다. `domain`과 `pricing`은 파일 입출력을 하지 않습니다.

## 4. 함수와 클래스
- 함수는 한 가지 일만 하고 30줄을 넘기지 않는 것을 권장합니다.
- 불변 데이터는 `@dataclass(frozen=True)`를 씁니다.
- 새 할인·요금 방식은 기존 클래스를 수정하지 말고 새 정책 클래스로 추가합니다.

## 5. 주석과 독스트링
- 독스트링과 주석은 한국어로 써도 됩니다.
- 규정을 구현한 코드에는 근거 조항을 적습니다. 예: `"""회차 시간 이내 출차는 무료(요금 규정 제5조)."""`
- 코드가 무엇을 하는지보다 왜 그렇게 하는지를 적습니다.

## 6. 예외
- 사용자 입력 오류와 데이터 오류는 `ParkfeeError` 하위 예외로 올리고 오류 코드를 붙입니다 ([로깅·에러 처리](logging-and-errors.md)).
- `except Exception`으로 삼키지 않습니다.

# 테스트 전략

| 항목 | 내용 |
|---|---|
| 문서 번호 | DEV-TEST-002 |
| 버전 | 2.0 (2026-05-25, 2026-05 정산 불일치 장애 후 개정) |
| 작성 | 정하늘 (QA) |

## 1. 원칙
- 요금·할인은 **규정 조항 단위로** 테스트합니다. 테스트 docstring에 근거 조항을 적습니다.
- 경계값을 반드시 넣습니다: 회차 시간과 회차 시간 + 1분, 기본 시간 경계(30분/31분), 단위 경계(40분/41분), 일 최대 요금 경계, 24시간 경계.
- 계산 순서가 결과를 바꾸는 경우(할인 순서, 절사 시점)는 순서가 틀리면 실패하는 숫자로 테스트합니다.

## 2. 구성

| 종류 | 위치 | 대상 | 비고 |
|---|---|---|---|
| 단위 테스트 | `tests/unit/` | 값 객체, 요금 방식, 할인 정책, 유스케이스, 저장소, 출력 형식 | 파일 대신 코드로 만든 설정과 가짜 저장소 사용 |
| 통합 테스트 | `tests/integration/` | CLI 명령 전체 | `data/` 복사본으로 실제 명령 실행 |

## 3. 커버리지 기준
- 라인 커버리지 90% 이상 (CI에서 미만이면 실패, `pyproject.toml`의 `fail_under`).
- 함수 커버리지 100%: 테스트가 한 번도 부르지 않는 함수가 없어야 합니다.
- 분기 커버리지 90% 이상을 목표로 합니다. 현재 1.6.0 기준 라인·분기 모두 100%입니다.

## 4. 실행

| 상황 | 명령 |
|---|---|
| 일반 실행 | `make test` |
| PR 전 | `make check` |
| 계산 과정을 확인하며 디버깅 | `python -m pytest -v -s --log-cli-level=DEBUG` |
| 특정 테스트만 | `python -m pytest tests/unit/test_checkout.py -k grace` |

## 5. 새 규칙을 추가할 때
1. 규정 조항마다 최소 한 개의 테스트를 먼저 씁니다. 규정에 계산 예가 있으면 그 숫자를 그대로 씁니다.
2. 기존 테스트가 깨지면 규정과 맞는지 먼저 확인합니다. 테스트를 고쳐 통과시키지 않습니다.
3. CLI 출력이 바뀌면 `tests/integration/test_cli.py`에 명령 단위 테스트를 추가합니다.

# 로깅·에러 처리

## 1. 로그 레벨

| 레벨 | 용도 | 예 |
|---|---|---|
| DEBUG | 계산 과정 추적 | 정산 시작, 적용 할인, 절사 전후 금액, 데이터 파일 읽음 |
| INFO | 운영상 의미 있는 사건 | 배치 시작·종료 |
| WARNING | 계산은 했지만 확인이 필요한 상황 | (현재 없음) |
| ERROR | 정산 실패 | 데이터 파일 오류 |

- CLI 기본 레벨은 WARNING이며 `--log-level DEBUG`로 바꿀 수 있습니다.
- 모듈마다 `logger = logging.getLogger(__name__)`를 씁니다.

## 2. 개인정보
- 로그에는 차량번호를 `mask_plate()`로 가려서 남깁니다. 예: `12가3456` → `12가****`.
- 고객 이름, 연락처는 parkfee가 다루지 않으며 로그에도 남기지 않습니다.

## 3. 오류 코드

| 코드 | 예외 | 의미 | CLI 종료 코드 |
|---|---|---|---|
| E1001 | `InvalidSessionError` | 세션 값 오류 (출차가 입차보다 빠름, 차량번호 없음) | 3 |
| E1002 | `InvalidTimeFormatError` | 시각·날짜 형식 오류 | 3 |
| E1003 | `UnknownLotError` | 등록되지 않은 주차장 | 3 |
| E2001 | `CouponNotFoundError` | 쿠폰 코드를 찾을 수 없음 | 3 |
| E3001 | `DataFileError` | 데이터 파일 없음·형식 오류 | 4 |

- 새 오류는 영역별 번호대를 따릅니다: E1xxx 입력, E2xxx 쿠폰, E3xxx 데이터 파일.
- 오류 메시지는 사용자가 바로 고칠 수 있게 무엇이 틀렸는지 적습니다.

## 4. CLI 종료 코드

| 종료 코드 | 의미 |
|---|---|
| 0 | 정상 |
| 2 | 명령 사용법 오류 (argparse) |
| 3 | 입력 오류 (E1xxx, E2xxx) |
| 4 | 데이터 파일 오류 (E3xxx) |

정산기는 종료 코드 4를 받으면 수동 정산 모드로 전환하고 장애 알림을 보냅니다 ([장애 대응 런북](../operations/incident-runbook.md)).

# 아키텍처 개요

| 항목 | 내용 |
|---|---|
| 문서 번호 | ARC-OVW-001 |
| 버전 | 1.6 (2026-08-25, parkfee 1.6.0 기준) |
| 작성 | 김민준 (정산플랫폼팀) |
| 검토 | 송다은, 임재현 (정산플랫폼팀) |

## 1. 품질 목표

| 우선순위 | 품질 속성 | 이유와 대응 |
|---|---|---|
| 1 | 정확성 | 정산 금액 오차는 바로 고객 민원과 매출 손실이 된다. 금액은 정수 원 단위 값 객체(Money)로만 계산하고, 규정 조항별 테스트를 둔다. |
| 2 | 변경 용이성 | 요금·할인 규정은 1년에 여러 번 바뀐다. 요금표·감면율은 데이터 파일로 분리하고(ADR-004), 계산 규칙은 교체 가능한 정책 객체로 둔다(ADR-001, ADR-003). |
| 3 | 테스트 용이성 | 계산 로직은 파일·시계·네트워크에 의존하지 않는다. 저장소는 인터페이스로 주입한다. |
| 4 | 이식성 | 정산기 펌웨어 번들(Python 3.10)에서 동작해야 하므로 표준 라이브러리만 쓴다. |

## 2. 계층 구조

```
presentation   CLI(argparse), 출력 형식(text/json)
     │
application    유스케이스: CheckoutService(출차 정산), DailySettlementService(일일 정산)
     │                      ports.py: 저장소 인터페이스
     ├──────────────┐
pricing          infrastructure
요금 방식·할인 정책    JSON·CSV 저장소, 설정 로더 (ports 구현)
     │              │
domain   엔터티와 값 객체: Money, ParkingSession, Coupon, SeasonPass, Receipt, 오류
```

### 의존 규칙
- `domain`은 어떤 계층에도 의존하지 않는다.
- `pricing`은 `domain`에만 의존한다.
- `application`은 `domain`, `pricing`, 그리고 `application/ports.py`의 인터페이스에만 의존한다. 파일 형식을 알지 못한다.
- `infrastructure`는 `domain`, `pricing`(설정 타입)에 의존하며 ports를 구현한다.
- `presentation`은 조립 지점(composition root)이다. 저장소 구현을 만들어 유스케이스에 주입한다.

## 3. 모듈 지도

| 모듈 | 책임 |
|---|---|
| `domain/money.py` | 금액 값 객체. 음수 금지, 차감 시 0원 하한, 비율 계산 시 원 미만 버림 |
| `domain/session.py` | 주차 세션과 주차 시간(분) 산정 |
| `domain/coupon.py` | 제휴 쿠폰 엔터티 (종류, 값, 발급 주차장, 유효기간) |
| `domain/season_pass.py` | 정기권과 적용 여부 판단 |
| `domain/receipt.py` | 정산 결과(영수증)와 적용 할인 내역 |
| `domain/errors.py` | 오류 코드가 있는 예외 |
| `pricing/schedule.py` | 주차장별 요금 정책(LotPolicy)과 전사 설정(PricingConfig) |
| `pricing/charge.py` | 요금 계산 방식 Strategy: 시간제, 정액제 |
| `pricing/discount.py` | 할인 정책 Strategy: 감면, 멤버십 |
| `pricing/pipeline.py` | 할인 정책을 순서대로 누적 적용하는 파이프라인 |
| `pricing/rounding.py` | 절사와 부가세 분리 |
| `application/checkout.py` | 출차 정산 유스케이스 |
| `application/settlement.py` | 일일 정산 집계 |
| `infrastructure/json_store.py` | 요금표·쿠폰·정기권 JSON 저장소 |
| `infrastructure/csv_sessions.py` | 입출차 기록 CSV 읽기 |
| `presentation/cli.py` | 명령 정의와 조립 |
| `presentation/formatters.py` | 출력 형식 Strategy: 텍스트 영수증, JSON |

## 4. 출차 정산 흐름

```
CLI(calc) ─▶ ParkingSession 생성
          ─▶ CheckoutService.checkout(session)
               1. PricingConfig.lot(lot_id)                 주차장 정책 조회
               2. SeasonPassRepository.find_by_plate()       정기권이면 0원 영수증
               3. parked_minutes <= grace_minutes            회차면 0원 영수증
               4. create_charge_strategy(schedule).charge()  할인 전 요금
               5. DiscountPipeline.run()                     감면 → 멤버십
               6. FloorRounding.apply()                      100원 미만 절사
               7. split_vat()                                공급가액·부가세
          ─▶ OutputFormatter.receipt(receipt)
```

## 5. 디자인 패턴 사용처

| 패턴 | 위치 | 이유 |
|---|---|---|
| Strategy | `ChargeStrategy`, `DiscountPolicy`, `OutputFormatter` | 주차장별 요금 방식, 할인 종류, 출력 형식이 독립적으로 바뀐다 |
| Factory | `create_charge_strategy`, `create_formatter` | 설정값으로 구현을 고르는 코드를 한곳에 모은다 |
| Pipeline | `DiscountPipeline` | 규정이 정한 할인 순서를 등록 순서로 표현한다 |
| Repository | `application/ports.py` + `infrastructure/json_store.py` | 파일 형식과 유스케이스를 분리하고 테스트에서 가짜 저장소를 쓴다 |
| Value Object | `Money` | 금액 규칙(음수 금지, 버림)을 한곳에서 지킨다 |

## 6. 확장 가이드

- **새 요금 방식**: `ChargeStrategy` 구현 추가 → `schedule.py`에 요금표 타입 추가 → `create_charge_strategy`와 설정 로더에 등록 → ADR 작성.
- **새 비율 할인**: `DiscountPolicy` 구현 추가 → `CheckoutService` 기본 파이프라인에 규정 순서대로 등록.
- **누적이 아닌 할인 규칙**: 파이프라인은 "앞 할인이 적용된 금액에 다음 할인을 적용"하는 규칙만 표현한다. 규정이 다른 방식의 조합을 요구하면 유스케이스(`CheckoutService`)에서 처리하고, 이유를 ADR로 남긴다.
- **새 출력 항목**: `Receipt`에 필드 추가 → `TextFormatter`, `JsonFormatter` 모두 수정 → `docs/api/cli.md` 갱신.

# 용어집

| 용어 | 정의 |
|---|---|
| 주차 시간 | 출차 시각 − 입차 시각. 1분 미만은 1분으로 올린다. |
| 회차 | 입차 후 회차 시간 이내에 출차하는 것. 요금을 받지 않는다. 주차장마다 회차 시간이 다르다. |
| 기본 요금 | 최초 기본 시간(30분)까지 부과하는 요금. |
| 단위 요금 | 기본 시간 이후 단위 시간(10분)마다 부과하는 요금. 단위 시간 미만도 1단위로 센다. |
| 일 최대 요금 | 입차 시각부터 24시간 구간마다 부과할 수 있는 요금의 상한. |
| 정액제 | 시간과 관계없이 시작된 24시간마다 같은 금액을 부과하는 방식 (환승주차장). |
| 감면 | 장애인·국가유공자·경형·저공해 자동차에 적용하는 비율 할인. 여러 개에 해당해도 하나만 적용한다. |
| 멤버십 할인 | 한결 멤버십 회원에게 감면 후 금액 기준으로 적용하는 할인. |
| 정기권 | 등록 차량 1대가 한 주차장을 한 달 동안 무료로 이용하는 권리. |
| 제휴 쿠폰 | 제휴 매장이 고객에게 발급하는 주차 쿠폰. 시간 쿠폰과 금액 쿠폰이 있다. |
| 시간 쿠폰 | 정해진 분만큼 무료 주차를 제공하는 쿠폰. |
| 금액 쿠폰 | 정해진 금액을 요금에서 빼 주는 쿠폰. |
| 쿠폰 반환 | 쿠폰을 사용 처리하지 않고 고객에게 돌려주는 것. 반환된 쿠폰은 유효기간 안에 다시 쓸 수 있다. |
| 절사 | 결제 금액의 100원 미만을 버리는 것. |
| 공급가액 / 부가세 | 결제 금액(부가세 포함)을 1.1로 나눈 값과 나머지. |
| 영업일 | 출차 시각이 속한 날짜(00:00~23:59). 일일 정산의 기준. |
| LPR | License Plate Recognition. 번호인식 카메라. |
| 사전 정산 | 출차 전에 앱이나 로비 정산기로 미리 결제하는 것. |

# 요금 규정

| 항목 | 내용 |
|---|---|
| 문서 번호 | POL-FEE-001 |
| 버전 | 3.2 |
| 개정일 / 시행일 | 2026-08-14 / 2026-08-25 |
| 소유 부서 | 서비스기획팀 (담당 이서연) |
| 승인 | 최현우 (서비스기획팀장), 정소영 (정산팀장) |

## 제1조 (목적)
이 규정은 한결파킹이 운영하는 주차장의 주차 요금 산정 기준을 정한다.

## 제2조 (적용 범위)
1. 이 규정은 HJ-01 한결타워, HJ-02 한결몰, HJ-03 한결역 환승주차장에 적용한다.
2. 감면, 멤버십 할인, 제휴 쿠폰은 「할인·감면 규정」을, 정기권은 「정기권 규정」을 따른다.

## 제3조 (요금표)

| 주차장 | 요금 방식 | 기본 요금 | 단위 요금 | 일 최대 요금 | 회차 시간 |
|---|---|---|---|---|---|
| HJ-01 한결타워 | 시간제 | 최초 30분 2,000원 | 10분당 500원 | 25,000원 | 10분 |
| HJ-02 한결몰 | 시간제 | 최초 30분 1,500원 | 10분당 500원 | 30,000원 | 15분 |
| HJ-03 한결역 환승주차장 | 정액제 | 24시간당 6,000원 | - | - | 10분 |

모든 요금은 부가가치세를 포함한 금액이다.

## 제4조 (주차 시간 산정)
1. 주차 시간은 출차 시각에서 입차 시각을 뺀 시간으로 하며, 1분 미만은 1분으로 올린다.
2. 입차·출차 시각은 번호인식(LPR) 기록을 기준으로 하며, 모든 시각은 한국 표준시(KST)로 다룬다.

## 제5조 (회차)
1. 주차 시간이 해당 주차장의 회차 시간 이하이면 요금을 받지 않는다.
2. 예: 한결타워에서 10분 이하 주차 후 출차하면 0원, 11분이면 기본 요금 2,000원을 받는다.

## 제6조 (시간제 요금 계산)
1. 주차 시간이 기본 시간(30분) 이하이면 기본 요금을 받는다.
2. 기본 시간을 넘으면 넘은 시간을 단위 시간(10분)으로 나누어 단위 요금을 더한다. 단위 시간 미만은 1단위로 센다.
3. 예: 한결타워 2시간 5분(125분) 주차 → 2,000원 + 10단위 × 500원 = 7,000원

## 제7조 (일 최대 요금)
1. 입차 시각부터 24시간을 1구간으로 하여, 구간마다 제6조로 계산한 요금이 일 최대 요금을 넘으면 일 최대 요금을 받는다.
2. 24시간을 모두 채운 구간의 요금은 일 최대 요금으로 한다. 마지막 구간은 그 구간의 주차 시간으로 제6조를 다시 적용한다.
3. 예: 한결타워 24시간 1분 주차 → 25,000원(첫 구간) + 2,000원(둘째 구간 1분) = 27,000원

## 제8조 (정액제 요금 계산)
HJ-03은 입차 시각부터 시작된 24시간 구간마다 6,000원을 받는다. 예: 24시간 1분 주차 → 12,000원

## 제9조 (정산 순서)
출차 정산은 다음 순서로 한다.

1. 정기권 확인 (「정기권 규정」)
2. 회차 확인 (제5조)
3. 요금 계산 (제6조~제8조)
4. 감면 적용 (「할인·감면 규정」 제2장)
5. 멤버십 할인 적용 (「할인·감면 규정」 제3장)
6. 절사 (제10조)
7. 부가세 분리 (제11조)

제휴 쿠폰을 사용하는 출차는 「할인·감면 규정」 제5장의 순서를 따른다.

## 제10조 (절사)
모든 할인을 적용한 뒤의 결제 금액에서 100원 미만을 한 번만 절사한다. 할인 단계마다 절사하지 않는다.

## 제11조 (부가세 표시)
1. 영수증에는 결제 금액을 공급가액과 부가세로 나누어 표시한다.
2. 공급가액은 결제 금액을 1.1로 나눈 값의 원 미만을 반올림한 금액으로 하고, 부가세는 결제 금액에서 공급가액을 뺀 금액으로 한다.

## 제12조 (입차 기록이 없는 경우)
입차 기록을 확인할 수 없는 차량은 해당 주차장 일 최대 요금 1일분을 받는다. 정액제 주차장은 1일 정액을 받는다. 이 처리는 운영팀이 정산기에서 수동으로 한다.

## 제13조 (요금 게시)
요금표는 주차장 출입구와 모든 정산기에 게시하고, 개정 시 시행 7일 전부터 변경 내용을 함께 게시한다.

# 할인·감면 규정

| 항목 | 내용 |
|---|---|
| 문서 번호 | POL-DSC-002 |
| 버전 | 2.3 |
| 개정일 / 시행일 | 2026-08-28 / 2026-09-15 |
| 소유 부서 | 서비스기획팀 (담당 이서연) |
| 검토 | 한지민 (고객경험팀), 최유진 (법무팀) |
| 승인 | 최현우 (서비스기획팀장) |

## 제1장 총칙

### 제1조 (목적)
이 규정은 주차 요금의 감면, 멤버십 할인, 제휴 쿠폰 적용 기준을 정한다.

### 제2조 (용어)
1. "감면"은 차량이나 이용자의 자격에 따라 요금의 일정 비율을 깎아 주는 것을 말한다.
2. "멤버십 할인"은 한결 멤버십 회원에게 주는 할인을 말한다.
3. "제휴 쿠폰"은 제휴 매장이 발급한 주차 쿠폰을 말한다.
4. "쿠폰 반환"은 쿠폰을 사용 처리하지 않고 고객에게 돌려주는 것을 말한다. 반환된 쿠폰은 유효기간 안에 다시 사용할 수 있다.

### 제3조 (다른 규정과의 관계)
요금 계산은 「요금 규정」을, 정기권은 「정기권 규정」을 따른다. 정기권으로 무료 처리되는 출차에는 이 규정의 할인을 적용하지 않는다.

## 제2장 감면

### 제4조 (감면 대상과 감면율)

| 구분 | 대상 | 감면율 |
|---|---|---|
| 장애인 | 장애인 자동차 표지를 붙이고 장애인 본인이 탄 차량 | 50% |
| 국가유공자 | 국가유공자 본인이 운전하는 차량 | 50% |
| 경형 자동차 | 자동차 등록 정보상 경형 자동차 | 30% |
| 저공해 자동차 | 자동차 등록 정보상 저공해 자동차(1·2종) | 30% |

### 제5조 (감면의 중복)
감면 대상에 둘 이상 해당하면 감면율이 가장 큰 감면 하나만 적용한다. 예: 장애인이 경형 자동차를 타면 장애인 감면 50%만 적용한다.

### 제6조 (증빙 확인)
1. 장애인·국가유공자 감면은 출차 시 운영팀이 화상 호출로 증빙을 확인한 경우에만 적용한다.
2. 경형·저공해 자동차는 자동차 등록 정보로 정산기가 자동 판별한다.
3. 장애인전용주차구역 운영은 「장애인전용주차구역 운영 지침」을 따른다.

### 제7조 (감면 금액)
감면 금액은 「요금 규정」 제6조~제8조로 계산한 요금에 감면율을 곱한 금액으로 하고, 원 미만은 버린다.

## 제3장 멤버십 할인

### 제8조 (대상과 할인율)
1. 한결 멤버십 회원에게 10%를 할인한다.
2. 멤버십 할인은 감면을 적용한 뒤의 금액에 적용하며, 원 미만은 버린다.
3. HJ-03 한결역 환승주차장은 지자체 협약 요금이므로 멤버십 할인을 적용하지 않는다.

### 제9조 (계산 예)
한결타워 2시간 5분 주차, 경형 자동차, 멤버십 회원:
7,000원 → 경형 감면 30%(2,100원) → 4,900원 → 멤버십 10%(490원) → 4,410원 → 절사 → 4,400원

## 제4장 정기권

### 제10조 (정기권)
정기권의 종류, 효력, 환불은 「정기권 규정」을 따른다.

## 제5장 제휴 쿠폰 (2026-09-15 시행)

### 제11조 (쿠폰의 종류)
1. 시간 쿠폰: 정해진 분(分)만큼 무료로 주차하게 하는 쿠폰
2. 금액 쿠폰: 정해진 금액을 요금에서 빼 주는 쿠폰

### 제12조 (사용 범위)
1. 쿠폰은 발급한 주차장에서만 사용할 수 있다. 다른 주차장에서 제시한 쿠폰은 사용 처리하지 않는다.
2. 출차 1회에 쿠폰 1장만 사용할 수 있다.
3. 쿠폰은 양도할 수 없으며 현금으로 바꾸어 주지 않는다.

### 제13조 (시간 쿠폰의 적용)
1. 시간 쿠폰의 무료 시간은 **요금을 계산하기 전에 주차 시간에서 먼저 뺀다.** 남은 주차 시간으로 「요금 규정」 제6조~제8조(시간제 요금, 일 최대 요금, 정액제 요금)를 적용한다.
2. 남은 주차 시간이 0분 이하이면 요금은 0원으로 한다.
3. 주차 시간 전체로 요금을 먼저 계산한 뒤 쿠폰 시간에 해당하는 금액을 빼는 방식으로 계산하지 않는다.
4. 계산 예: 한결몰 11시간(660분) 주차, 120분 시간 쿠폰
   - 바른 계산: 660분 − 120분 = 540분 → 1,500원 + 51단위 × 500원 = 27,000원
   - 잘못된 계산: 660분 요금 33,000원 → 일 최대 30,000원 → 120분어치 6,000원 차감 → 24,000원

### 제14조 (금액 쿠폰의 적용)
금액 쿠폰은 「요금 규정」 제6조~제8조로 계산한 요금(일 최대 요금 적용 후)에서 쿠폰 금액을 뺀다. 뺀 결과가 0원보다 작으면 0원으로 한다.

### 제15조 (다른 할인과의 관계)
1. 쿠폰은 감면·멤버십 할인과 함께 적용하지 않는다.
2. 다음 두 금액을 각각 계산하고 「요금 규정」 제10조의 절사까지 마친 뒤, 낮은 금액으로 정산한다.
   - ① 쿠폰만 적용한 금액
   - ② 쿠폰 없이 감면·멤버십 할인을 적용한 금액
3. ①이 ②보다 낮으면 ①로 정산하고 쿠폰을 사용 처리한다.
4. ②가 ①보다 낮거나 **두 금액이 같으면 ②로 정산하고 쿠폰은 반환한다.** 고객이 쿠폰을 다음 방문에 쓸 수 있도록 하기 위함이다.
5. 계산 예 (한결몰, 2시간 주차, 할인 전 요금 6,000원)
   - 경형 자동차·멤버십 회원, 1,000원 금액 쿠폰: ① 5,000원, ② 6,000원 → 4,200원 → 3,780원 → 3,700원 → **3,700원(②), 쿠폰 반환**
   - 멤버십 회원, 60분 시간 쿠폰: ① 60분 → 3,000원, ② 5,400원 → **3,000원(①), 쿠폰 사용**

### 제16조 (회차 출차와 쿠폰)
1. 회차 시간 안에 출차하면 「요금 규정」 제5조에 따라 요금은 0원이며, 쿠폰은 사용 처리하지 않고 반환한다.
2. 회차 여부는 쿠폰 시간을 빼기 전의 실제 주차 시간으로 판단한다.

### 제17조 (유효기간)
1. 쿠폰의 유효기간은 **출차 시각을 기준으로** 판단한다. 입차 시각에 유효했더라도 출차 시각에 유효기간이 지났으면 만료된 쿠폰으로 보고 적용하지 않는다.
2. 출차 시각이 유효기간 시작 전이면 사용할 수 없으며 쿠폰은 반환한다.
3. 유효기간의 시작 시각과 종료 시각은 기간에 포함한다.
4. 예: 유효기간이 9월 10일 23:59:59까지인 쿠폰을 9월 10일 22:00 입차, 9월 11일 01:00 출차한 차량이 제시하면 만료 쿠폰으로 처리하고 일반 정산한다.

### 제18조 (정기권 출차와 쿠폰)
정기권으로 무료 처리되는 출차에는 쿠폰을 사용 처리하지 않고 반환한다.

### 제19조 (영수증 표시)
쿠폰을 제시한 출차의 영수증에는 쿠폰 코드와 처리 결과(사용, 반환, 만료)를 표시한다.

# CLI 명세

| 항목 | 내용 |
|---|---|
| 문서 번호 | API-CLI-001 |
| 버전 | 1.6 (parkfee 1.6.0) |
| 작성 | 송다은 (정산플랫폼팀) |

정산기와 앱 백엔드는 `--format json` 출력을 파싱합니다. JSON 필드를 바꾸거나 지우면 연동 시스템이 깨지므로, 필드는 추가만 하고 변경·삭제는 연동팀과 협의합니다.

## 1. 전역 옵션

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--data-dir DIR` | `data` (환경 변수 `PARKFEE_DATA_DIR`가 있으면 그 값) | 요금표·쿠폰·정기권 파일 위치 |
| `--log-level LEVEL` | `WARNING` | `DEBUG`, `INFO`, `WARNING`, `ERROR` |
| `--version` | - | 버전 출력 |

전역 옵션은 명령 이름 앞에 씁니다. 예: `parkfee --data-dir /opt/parkfee/data calc ...`

## 2. calc — 출차 1건 정산

```
parkfee calc --lot LOT --plate PLATE --entry DATETIME --exit DATETIME
             [--vehicle-type {general,compact,low-emission}]
             [--reduction {none,disabled,veteran}]
             [--member] [--format {text,json}]
```

| 옵션 | 필수 | 설명 |
|---|---|---|
| `--lot` | 예 | 주차장 ID (HJ-01, HJ-02, HJ-03) |
| `--plate` | 예 | 차량번호 |
| `--entry` | 예 | 입차 시각, 예: `2026-09-01T09:00` 또는 `2026-09-01 09:00:30` |
| `--exit` | 예 | 출차 시각 |
| `--vehicle-type` | 아니오 | 차종. 기본 `general` |
| `--reduction` | 아니오 | 감면 구분. 기본 `none`. 증빙 확인 후에만 지정 |
| `--member` | 아니오 | 한결 멤버십 회원 |
| `--format` | 아니오 | `text`(기본) 또는 `json` |

### 2.1 텍스트 출력 예

```
[한결파킹 주차 영수증]
주차장   : 한결타워 (HJ-01)
차량번호 : 12가3456
입차     : 2026-09-01 09:00
출차     : 2026-09-01 11:05
주차시간 : 2시간 5분
주차요금 : 7,000원
할인     : 경형 자동차 감면 30% -2,100원
할인     : 한결 멤버십 10% -490원
결제금액 : 4,400원 (공급가액 4,000원 / 부가세 400원)
```

### 2.2 JSON 출력

```json
{
  "lot_id": "HJ-01",
  "lot_name": "한결타워",
  "plate": "12가3456",
  "entry_at": "2026-09-01T09:00:00",
  "exit_at": "2026-09-01T11:05:00",
  "parked_minutes": 125,
  "charge": 7000,
  "discounts": [
    {"type": "reduction", "name": "경형 자동차 감면 30%", "amount": 2100},
    {"type": "membership", "name": "한결 멤버십 10%", "amount": 490}
  ],
  "total": 4400,
  "vat": {"supply": 4000, "tax": 400},
  "grace": false,
  "season_pass": false
}
```

| 필드 | 타입 | 설명 |
|---|---|---|
| `charge` | int | 할인 전 요금 (회차·정기권이면 0) |
| `discounts[].type` | string | `reduction`, `membership` |
| `discounts[].amount` | int | 할인 금액 (절사 전) |
| `total` | int | 최종 결제 금액 (절사 후) |
| `vat.supply`, `vat.tax` | int | 공급가액, 부가세 |
| `grace` | bool | 회차 무료 여부 |
| `season_pass` | bool | 정기권 무료 여부 |

## 3. batch — 일일 정산 리포트

```
parkfee batch SESSIONS_CSV [--format {text,json}]
```

입력 CSV 형식은 [데이터 모델](../architecture/data-model.md) 3절을 따릅니다.

```json
{
  "lots": [
    {"lot_id": "HJ-01", "lot_name": "한결타워", "sessions": 6, "free_sessions": 2,
     "charge": 38500, "discount": 6015, "revenue": 32400}
  ],
  "total_sessions": 16,
  "total_revenue": 79900
}
```

`revenue`는 절사 후 결제 금액의 합이므로 `charge - discount`와 절사 차액만큼 다를 수 있습니다.

## 4. coupon show — 쿠폰 조회

```
parkfee coupon show CODE [--format {text,json}]
```

```json
{
  "code": "HJM-2609-0001",
  "kind": "time",
  "value": 60,
  "lot_id": "HJ-02",
  "partner": "한결시네마",
  "valid_from": "2026-09-01T00:00:00",
  "valid_until": "2026-09-30T23:59:59",
  "description": "한결시네마 무료 주차 60분"
}
```

## 5. 종료 코드
0 정상, 2 사용법 오류, 3 입력 오류(E1xxx, E2xxx), 4 데이터 파일 오류(E3xxx). 오류 메시지는 표준 오류로 `[코드] 메시지` 형식으로 출력합니다.
