# 배포 절차

| 항목 | 내용 |
|---|---|
| 문서 번호 | OPS-DEP-001 |
| 버전 | 1.4 (2026-07-20) |
| 작성 | 한도윤 (인프라팀) |

## 1. 배포 대상

| 대상 | 방식 | 주기 |
|---|---|---|
| 앱 백엔드 | 사내 패키지 저장소의 parkfee 휠 설치 | 릴리즈마다 |
| 무인 정산기 | 정산기 펌웨어 번들에 포함 | 월 1회 정기 (매월 둘째 화요일 02:00) |
| 일일 정산 배치 | 배치 서버 가상 환경에 설치 | 릴리즈마다 |
| 데이터 파일 | 배포 파이프라인이 각 대상의 데이터 디렉터리에 복사 | 매일 05:00 (쿠폰·정기권), 요금표는 승인 시 |

## 2. 코드 릴리즈
1. `main`에서 `make check` 통과 확인
2. `CHANGELOG.md` 정리, `pyproject.toml`과 `src/parkfee/__init__.py`의 버전 갱신
3. 태그 `v<버전>` 푸시 → CI가 휠을 빌드해 사내 패키지 저장소에 올림
4. 스테이징 정산기(HJ-01 지하 1층 1대)에 설치하고 회귀 시나리오 20건 확인 (QA 정하늘)
5. 운영 반영 후 1시간 동안 정산 오류율 모니터링

## 3. 요금표 변경 배포
1. 기획팀이 규정 개정본을 승인하고 시행일을 확정
2. 정산플랫폼팀이 `fee_schedules.json` 변경 PR 작성 (기획팀 승인 필수)
3. 시행일 전날 18:00까지 스테이징 반영과 검증
4. 시행일 00:00 배포 파이프라인이 운영 데이터 디렉터리를 교체
5. 정산기 요금 게시물 교체는 운영팀이 시행 7일 전 완료 (요금 규정 제13조)

## 4. 롤백
- 코드: 이전 버전 휠로 재설치 (앱 백엔드·배치 5분 이내, 정산기는 원격 롤백 30분 이내)
- 데이터 파일: 배포 파이프라인의 직전 스냅숏으로 교체
- 롤백 판단은 [장애 대응 런북](incident-runbook.md)을 따릅니다.
