# 서비스 개요

| 항목 | 내용 |
|---|---|
| 문서 번호 | PRD-OVW-001 |
| 버전 | 1.4 (2026-08-20) |
| 작성 | 이서연 (서비스기획팀) |
| 검토 | 김민준 (정산플랫폼팀), 박지훈 (운영팀) |

## 1. 회사와 서비스

한결파킹은 한결그룹 계열 건물과 역세권 환승주차장을 위탁 운영하는 주차 운영사입니다.
번호인식(LPR) 기반 무인 출입, 무인 정산기, 한결파킹 앱 사전 정산을 제공합니다.

## 2. 운영 주차장

| ID | 이름 | 위치 유형 | 면수 | 주 이용자 |
|---|---|---|---|---|
| HJ-01 | 한결타워 | 오피스 빌딩 지하 1~4층 | 420면 | 입주사 방문객, 정기권 입주사 직원 |
| HJ-02 | 한결몰 | 쇼핑몰 지하 1~3층 | 680면 | 쇼핑·영화 관람 고객 (제휴 매장 쿠폰 사용) |
| HJ-03 | 한결역 환승주차장 | 지상 노외주차장 | 310면 | 출퇴근 환승 이용자 |

## 3. 이해관계자

- **고객**: 주차장 이용자. 정산 금액과 영수증의 정확성을 기대합니다.
- **제휴 매장**: 한결몰·한결타워 입점 매장. 고객에게 주차 쿠폰을 발급하고 월말에 정산합니다.
- **운영팀**: 현장 관리, 감면 증빙 확인, 수동 정산 처리.
- **서비스기획팀**: 요금·할인 규정의 소유자. 규정 개정을 승인합니다.
- **정산팀(재무)**: 일일·월간 매출 정산, 제휴 매장 청구.
- **법무팀**: 개인정보, 영상정보처리기기, 장애인전용주차구역 관련 법규 검토.
- **정산플랫폼팀**: parkfee 개발·운영.

## 4. 시스템 구성

```
[LPR 카메라] ──입출차 기록──▶ [출입 관리 서버] ──▶ [무인 정산기 / 앱 백엔드]
                                                          │
                                                          ▼
                                                   [parkfee 엔진]  ◀── 요금표·쿠폰·정기권 데이터
                                                          │
                                                          ▼
                                                   [PG 결제 모듈] ──▶ [정산 DB] ──▶ [일일 정산 배치]
```

## 5. parkfee의 범위

| 범위 안 | 범위 밖 |
|---|---|
| 출차 1건의 요금 계산과 영수증 데이터 생성 | 결제 승인·취소 (PG 결제 모듈) |
| 감면·멤버십·정기권·회차 적용 | 감면 증빙 확인 (현장 운영팀, 정산기 화면) |
| 일일 정산 집계 | 주차권 분실 처리, 사전 정산 후 출차 유예 판단 (출입 관리 서버) |
| 제휴 쿠폰 조회 | 제휴 쿠폰 발급·제휴 매장 청구 (제휴운영 시스템) |
